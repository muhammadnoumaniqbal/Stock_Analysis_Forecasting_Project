# Stock_Analysis_Forecasting_Project
A complete Stock Market Analysis and Time Series Forecasting Web Application built using Python and Streamlit.
This project focuses on data visualization, technical analysis, and machine learning-based time series forecasting for stock prices.
## Project Overview
This application allows users to:
- Analyze historical stock data
- Visualize stock trends using interactive charts
- Apply technical indicators
- Forecast stock closing prices for the next 30 days using a Time Series ARIMA model
The app supports popular stocks like TSLA, AAPL, and AMZN and provides an intuitive, interactive dashboard experience.
##Features
Stock Information
- Real-time and historical stock data using Yahoo Finance (yfinance)
- Company fundamentals:
- Market Capitalization
- Beta
- EPS & P/E Ratio
- Sector & Business Summary
## Interactive Data Visualization
Built using Plotly for dynamic and responsive charts:
- Line Charts (Open, Close, High, Low)
- Candlestick Charts
- Simple Moving Average (SMA 50)
- RSI (Relative Strength Index)
- MACD Indicator
## Time Series Forecasting (Machine Learning)
- Implemented ARIMA Time Series Model
- Stationarity check using ADF Test
- Rolling mean smoothing
- Differencing for stationarity
- Data scaling using StandardScaler
- Model evaluation using RMSE
- Forecasts next 30 days closing prices
Results are displayed in:
- Forecast tables
-Forecast line charts with historical comparison
## User-Friendly Streamlit Dashboard
- Multi-page Streamlit application:
- Stock Overview
- Stock Analysis
- Stock Prediction
Interactive inputs for ticker symbols and date ranges
Clean and responsive UI layout
